# Data Notes

This project does not redistribute private diary entries or clinical data.

## Included Evaluation Data

The reproducible benchmark data used for thesis figures is generated by `scripts/generate_figures.py` from project-owned sources:

- emotion lexicon terms in `model.py`
- phrase hints in `model.py`
- seed examples in `evaluate.py`
- additional diary-style mixed-emotion examples embedded in the figure generation script

When the script runs, it writes the generated benchmark to:

```text
figures/benchmark_dataset.json
```

## Privacy Position

User-written reflections are processed locally by the running Python server. The frontend stores history in browser `localStorage`; the backend does not save diary text to disk.

## External Data

No large external dataset is required to run the packaged prototype. If a future version adds a fine-tuned transformer model or external training dataset, document the download source, license, preprocessing steps, and privacy constraints here instead of committing private raw data.
